# STM32F407 ClickerV2 SOES

EtherCAT slave implementation for STM32F407VG microcontroller on MikroElektronika Clicker 2 for STM32 board using SOES (Simple Open EtherCAT Slave) stack.

## Hardware

- **Board**: MikroElektronika Clicker 2 for STM32
- **MCU**: STM32F407VGT6
  - ARM Cortex-M4F @ 168MHz
  - 1024KB Flash
  - 128KB RAM
  - 64KB CCM RAM
- **EtherCAT PHY**: LAN9252 (via mikroBUS socket)

## Memory Layout

The project uses a partitioned flash layout to support bootloader and persistent storage:

| Region      | Address       | Size   | Purpose                          |
|-------------|---------------|--------|----------------------------------|
| FLASH_BLD   | 0x08000000    | 48KB   | Bootloader                       |
| FLASH_PAR   | 0x0800C000    | 16KB   | Parameters (`.params` section)   |
| FLASH_CAL   | 0x08010000    | 64KB   | Calibration (`.calib` section)   |
| FLASH_APP   | 0x08020000    | 128KB  | Application code                 |
| FLASH_NXT   | 0x08040000    | 256KB  | Reserved for future use          |

## Build Requirements

- CMake >= 3.22
- ARM GCC toolchain (arm-none-eabi-gcc) 13.2.1 or later
- GNU Make or Ninja build system

## Dependencies

The project uses git submodules for external dependencies:

- **SOES**: EtherCAT slave stack from [Advanced-Robotics-Facility/SOES](https://github.com/Advanced-Robotics-Facility/SOES) (branch: `main_advr`)
- **uc_test**: Test framework from [alessiomargan/uc-test](https://github.com/alessiomargan/uc-test) (branch: `soes_main`)

## Getting Started

### Clone the Repository

```bash
git clone --recurse-submodules git@github.com:alessiomargan/stm32f407-clickerV2-soes.git
cd stm32f407-clickerV2-soes
```

If you already cloned without submodules:

```bash
git submodule update --init --recursive
```

### Build the Project

```bash
make
```

This will:
1. Configure the CMake project (Debug preset)
2. Build all targets
3. Generate `.hex` and `.bin` files
4. Copy the binary to `~/.ecat_master/firmware/st_lan9252.bin`

Build artifacts are located in `build/Debug/`.

### Build Configuration

The project uses CMake presets defined in `CMakePresets.json`. The default preset is `Debug`.

**Compiler flags:**
- C17 standard (GNU extensions enabled)
- Cortex-M4 with hardware FPU
- Nano newlib specs
- Stack usage analysis enabled
- Floating-point printf support

**Optimization levels:**
- Debug: `-O0 -g3`
- Release: `-Os`

### Flash Programming

After building, flash the firmware to the target:

```bash
# Using st-flash
st-flash write build/Debug/stm32f407-clickerV2-soes.bin 0x8020000

# Using OpenOCD
openocd -f interface/stlink.cfg -f target/stm32f4x.cfg \
  -c "program build/Debug/stm32f407-clickerV2-soes.elf verify reset exit"
```

**Note**: The application starts at `0x8020000` (FLASH_APP region), not the default `0x8000000`.

## Configuration

### STM32CubeMX

The project was initialized with STM32CubeMX. Hardware configuration:
- SPI1: EtherCAT communication with LAN9252
- TIM2: EtherCAT synchronization timer
- UART2: Debug console (optional)

To regenerate code from `stm32f407-clickerV2-soes.ioc`:
1. Open the `.ioc` file in STM32CubeMX
2. Generate code
3. The CMake integration will pick up changes automatically

### Build System

The build system is organized as:
- `CMakeLists.txt`: Top-level configuration
- `cmake/stm32cubemx/CMakeLists.txt`: Auto-generated by STM32CubeMX
- `cmake/soes.cmake`: SOES stack and uc_test integration
